# Eventique Nepal (Android)

Find events, get tickets, and check guests in with QR codes.

**This is a test version in demo mode.** It shows sample events, sign-in is simulated and nothing you
enter is saved. No ticket from it is real. It has had automated tests only and does not update itself.

## Install

Open the APK and, if Android asks, allow your browser or file app to install apps. If installing over an
earlier copy fails, uninstall that copy first.

The camera is used only to scan ticket QR codes.
