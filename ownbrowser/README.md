# OwnBrowser

A small personal browser with lockable profiles and ad blocking.

**This is a test version.** It has had automated tests only, has not been security reviewed,
and does not update itself. Use it at your own risk, and not for anything sensitive.

## Install

The apps are not signed with a paid developer certificate, so your device will warn you.

- **Android:** open the APK and allow your browser or file app to install apps. To replace an
  earlier version, uninstall it first. **Uninstalling erases its profiles.**
- **Windows:** if SmartScreen appears, choose More info, then Run anyway.
- **macOS:** open the app, then allow it under System Settings > Privacy & Security >
  Open Anyway. Managed work computers may refuse unsigned apps.
