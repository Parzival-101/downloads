# LifeOS (Android)

Your life. Organized. Money, loans, vehicle, habits, trips and projects, kept on your phone.

**This is an early test version.** It has had automated tests only and has not been tried on a real
phone yet. Do not rely on it as your only record of anything. It does not send reminders or
notifications, and amounts are in Nepali rupees only. It does not update itself.

## Install

Open the APK and, if Android asks, allow your browser or file app to install apps.

This copy is signed with a test key. A later official version cannot be installed over it: first make
a backup in LifeOS (More > Backup & your data), uninstall, install the new one and restore.

## Ads and data

Your records stay on the phone; LifeOS has no account or server. The free version shows banner ads
using Google's test ad units, and Google's ad software collects device information such as the
advertising ID and IP address. Buying Ad-Free does not work in this test version.
